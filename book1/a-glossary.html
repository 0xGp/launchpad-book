Appendix A

Glossary

TermMeaning
AMMAutomated market maker: a pool that trades by formula instead of matching buyers and sellers.
Basis point (bp)0.01%. 100 bps = 1% (pump.fun's fee).
bigintJavaScript's arbitrary-precision integer type. Required for token math above 2^53.
Bonding curveA formula that sets price from how much has been bought. Here: constant product with virtual reserves.
BumpThe extra byte (255 down to 0) used to push a PDA off the Ed25519 curve.
Candle (OHLCV)Open, high, low, close and volume for one time bucket.
CPICross-program invocation: one program calling another.
DAMM v2Meteora's AMM that DBC pools migrate into.
DBCMeteora's Dynamic Bonding Curve program: config → virtual pool → DAMM v2.
DiscriminatorThe first 8 bytes of an Anchor account, instruction or event that identify its type (sha256 prefix).
emit_cpiAnchor's way to emit an event as a self-CPI, so it shows up as inner-instruction data instead of a log.
Graduation / migrationThe curve completes and its liquidity moves into an AMM pool.
IdempotentDoing it twice has the same effect as doing it once.
LamportThe smallest unit of SOL. 1 SOL = 1,000,000,000 lamports.
LP tokenA receipt for liquidity in a pool. Burned (pump.fun, per class notes) or locked (Meteora DBC) after migration.
Mint authorityThe key allowed to create new tokens. It should be a program PDA or revoked.
PDAProgram-derived address: derived from seeds + program ID, with no private key, and only the program can sign for it.
PermissionlessAnyone may call it.
Raw unitsInteger amounts before decimals (this book assumes 6 token decimals).
Real reservesWhat the curve actually holds (real SOL, real tokens for sale).
SlippageThe gap between the quoted and the executed price. Limited by max_sol_cost / min_sol_output.
Virtual reservesPretend starting reserves that set the price curve (30 SOL / 1.073B tokens on pump.fun).
