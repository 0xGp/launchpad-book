Part 9.2 · Capstone part 2

Capstone 2: the program state machine and idempotent migrate

Now we wrap the engine in a "program". It stores every coin's curve, runs create, buy, sell and migrate, and writes the events your indexer reads. This is a small version of a launchpad program, written in TypeScript so you can see every part.

1 Everyday analogy

Two okada riders both see the same passenger at the junction and race to carry her. The passenger can only be carried once. Whoever arrives second finds her already on the first bike, so he just rides away, and nobody gets paid twice. If the first rider's bike breaks down halfway, the trip isn't "half done and forgotten". The next rider continues from where it stopped.

2 Design question

pump.fun's public docs say migrate is permissionless and idempotent. A coin's curve has just completed, and two bots call migrate(mint) at almost the same moment.

(1) What must your program check and store so the second call does nothing harmful? It mustn't create a second pool, move the money twice, or emit a second MigrateEvent. (2) What happens if the first call crashes halfway through?

Try to answer on your own first, in plain English. A gut answer is fine.

Reveal answer

(1) Store a status on the coin (Trading → Complete → Migrating → Migrated) and check it first. If the status is Migrated, return without doing anything: no pool, no transfer, no event. Create the pool at a deterministic address (a PDA in a real program). If it already exists, don't create it again. On Solana, two transactions that write the same account are processed one after the other, so the second one always sees the first one's result.

(2) Inside one Solana transaction, a failure rolls everything back, so there's no "half". If migration is split across several transactions (Meteora DBC tracks a MigrationProgress state for this Real: Meteora DBC), store the step after each one, and make every step check its own step before running. A retry then resumes from the saved step. Our clone General pattern / our clone models both cases.

3 Simple explanation

  • Atomic instructions: our simulator snapshots state, runs the instruction, and restores the snapshot if anything throws, just like a Solana transaction.
  • Events with a sequence number: each event gets seq and slot. That gives the indexer a strict order and a natural unique key.
  • Status checks: buy and sell require Trading. migrate requires Complete (or Migrating when resuming), and it's a no-op when the status is Migrated.
  • Money moves once: after moving liquidity, realSolReserves is set to 0 and the step is saved, so the transfer can't happen twice.

5 TypeScript code

code/program.ts
// Capstone part 2 — the launchpad "program" as a TypeScript state machine.
// OUR CLONE'S DESIGN. It mimics the shape of pump.fun's public instructions
// (create / buy / sell / migrate, permissionless + idempotent migrate) but is NOT pump.fun's code.
import { Curve, newCurve, applyBuy, applySell } from "./engine.ts";

export type Status = "Trading" | "Complete" | "Migrating" | "Migrated";
// Migration is split into steps so a crash between transactions can resume (same idea as
// Meteora DBC's MigrationProgress field; the step names here are ours).
export type MigrationStep = "None" | "PoolCreated" | "LiquidityMoved" | "LpBurned";

export interface CoinState {
  mint: string;
  creator: string;
  curve: Curve;
  status: Status;
  step: MigrationStep;
  poolId?: string;
}

export type ProgramEvent =
  | { kind: "CreateEvent"; seq: number; slot: number; mint: string; creator: string }
  | { kind: "TradeEvent"; seq: number; slot: number; signature: string; mint: string; user: string;
      isBuy: boolean; tokenAmount: bigint; solAmount: bigint; fee: bigint;
      virtualSolReserves: bigint; virtualTokenReserves: bigint }
  | { kind: "CompleteEvent"; seq: number; slot: number; mint: string }
  | { kind: "MigrateEvent"; seq: number; slot: number; mint: string; poolId: string; sol: bigint; tokens: bigint };

type EventInput = ProgramEvent extends infer E ? E extends ProgramEvent ? Omit<E, "seq" | "slot"> : never : never;

export class LaunchpadProgram {
  coins = new Map<string, CoinState>();
  events: ProgramEvent[] = [];
  pools = new Map<string, { sol: bigint; tokens: bigint; lpBurned: boolean }>();
  slot = 1;
  private seq = 0;
  /** test hook: throw when migration reaches this step, to simulate a crash between txs */
  crashAfter?: MigrationStep;

  private emit(e: EventInput) {
    this.events.push({ ...e, seq: ++this.seq, slot: this.slot } as ProgramEvent);
  }

  /** Every instruction is all-or-nothing, like a Solana transaction: snapshot, run, roll back on error. */
  private atomic<T>(fn: () => T): T {
    const snap = structuredClone({ coins: this.coins, events: this.events, pools: this.pools, seq: this.seq });
    try {
      const out = fn();
      this.slot++;
      return out;
    } catch (err) {
      this.coins = snap.coins; this.events = snap.events; this.pools = snap.pools; this.seq = snap.seq;
      throw err;
    }
  }

  private coin(mint: string): CoinState {
    const c = this.coins.get(mint);
    if (!c) throw new Error("CoinNotFound");
    return c;
  }

  create(mint: string, creator: string) {
    return this.atomic(() => {
      if (this.coins.has(mint)) throw new Error("AlreadyExists"); // like an `init` account constraint
      this.coins.set(mint, { mint, creator, curve: newCurve(), status: "Trading", step: "None" });
      this.emit({ kind: "CreateEvent", mint, creator });
    });
  }

  buy(signature: string, user: string, mint: string, amount: bigint, maxSolCost: bigint) {
    return this.atomic(() => {
      const c = this.coin(mint);
      if (c.status !== "Trading") throw new Error("CurveComplete");
      const q = applyBuy(c.curve, amount, maxSolCost);
      this.emit({ kind: "TradeEvent", signature, mint, user, isBuy: true, tokenAmount: q.tokensOut,
        solAmount: q.solCost, fee: q.fee, virtualSolReserves: c.curve.virtualSolReserves,
        virtualTokenReserves: c.curve.virtualTokenReserves });
      if (c.curve.complete) { c.status = "Complete"; this.emit({ kind: "CompleteEvent", mint }); }
      return q;
    });
  }

  sell(signature: string, user: string, mint: string, amount: bigint, minSolOutput: bigint) {
    return this.atomic(() => {
      const c = this.coin(mint);
      if (c.status !== "Trading") throw new Error("CurveComplete");
      const q = applySell(c.curve, amount, minSolOutput);
      this.emit({ kind: "TradeEvent", signature, mint, user, isBuy: false, tokenAmount: amount,
        solAmount: q.solOut, fee: q.fee, virtualSolReserves: c.curve.virtualSolReserves,
        virtualTokenReserves: c.curve.virtualTokenReserves });
      return q;
    });
  }

  /**
   * Permissionless + idempotent migrate. Anyone may call it; calling it again is a no-op.
   * Each step checks-and-records progress, so a crash resumes instead of repeating work.
   * Returns "noop" when there is nothing to do.
   */
  migrate(_caller: string, mint: string): "migrated" | "noop" {
    return this.atomic(() => {
      const c = this.coin(mint);
      if (c.status === "Migrated") return "noop"; // second bot lands here: no pool, no transfer, no event
      if (c.status === "Trading" || !c.curve.complete || c.curve.realTokenReserves !== 0n)
        throw new Error("CurveNotComplete");
      c.status = "Migrating";
      const poolId = `pool:${mint}`; // deterministic id (like a PDA) so it can never be created twice

      if (c.step === "None") {
        if (!this.pools.has(poolId)) this.pools.set(poolId, { sol: 0n, tokens: 0n, lpBurned: false });
        c.poolId = poolId; c.step = "PoolCreated";
        this.checkpoint(c, "PoolCreated");
      }
      if (c.step === "PoolCreated") {
        const pool = this.pools.get(poolId)!;
        const tokensForPool = c.curve.tokenTotalSupply - 793_100_000_000_000n; // the unsold 206.9M
        pool.sol += c.curve.realSolReserves; pool.tokens += tokensForPool;
        c.curve.realSolReserves = 0n; c.step = "LiquidityMoved";
        this.checkpoint(c, "LiquidityMoved");
      }
      if (c.step === "LiquidityMoved") {
        this.pools.get(poolId)!.lpBurned = true; c.step = "LpBurned";
      }
      const pool = this.pools.get(poolId)!;
      c.status = "Migrated";
      this.emit({ kind: "MigrateEvent", mint, poolId, sol: pool.sol, tokens: pool.tokens });
      return "migrated";
    });
  }

  /** In a real program each step would be its own transaction; a crash here keeps the saved step. */
  private checkpoint(c: CoinState, step: MigrationStep) {
    if (this.crashAfter === step) {
      this.crashAfter = undefined;
      // persist progress so far (the earlier tx committed), then die
      const saved = structuredClone(c);
      const savedPools = structuredClone(this.pools);
      throw Object.assign(new Error(`Crash after ${step}`), { saved, savedPools });
    }
  }

  /** Simulates "the earlier transactions did commit": apply what a crash left on-chain. */
  restoreAfterCrash(err: any) {
    this.coins.set(err.saved.mint, err.saved);
    this.pools = err.savedPools;
  }
}

code/program.test.ts
import assert from "node:assert/strict";
import { LaunchpadProgram } from "./program.ts";

const ONE_K_SOL = 10n ** 12n;
const p = new LaunchpadProgram();
p.create("MINT1", "alice");
assert.throws(() => p.create("MINT1", "eve"), /AlreadyExists/);
p.buy("sig1", "bob", "MINT1", 10_000_000_000_000n, 285_042_334n); // exact total from chapter 2
assert.throws(() => p.migrate("bot1", "MINT1"), /CurveNotComplete/);
p.buy("sig2", "carol", "MINT1", 900_000_000_000_000n, ONE_K_SOL); // partial fill completes the curve
assert.equal(p.coins.get("MINT1")!.status, "Complete");
assert.throws(() => p.buy("sig3", "dave", "MINT1", 1n, ONE_K_SOL), /CurveComplete/);

// two bots race to migrate
assert.equal(p.migrate("bot1", "MINT1"), "migrated");
assert.equal(p.migrate("bot2", "MINT1"), "noop");
assert.equal(p.pools.size, 1);
assert.equal(p.events.filter(e => e.kind === "MigrateEvent").length, 1);
const pool = p.pools.get("pool:MINT1")!;
console.log("pool after migrate:", pool);

// crash halfway, then resume
const q = new LaunchpadProgram();
q.create("MINT2", "alice");
q.buy("s1", "bob", "MINT2", 793_100_000_000_000n, ONE_K_SOL);
const solInCurve = q.coins.get("MINT2")!.curve.realSolReserves;
q.crashAfter = "PoolCreated";
try { q.migrate("bot1", "MINT2"); assert.fail("should crash"); }
catch (e: any) { assert.match(e.message, /Crash after PoolCreated/); q.restoreAfterCrash(e); }
assert.equal(q.coins.get("MINT2")!.step, "PoolCreated");
assert.equal(q.migrate("bot2", "MINT2"), "migrated"); // resumes from the saved step
assert.equal(q.migrate("bot3", "MINT2"), "noop");
assert.equal(q.pools.size, 1);
assert.equal(q.pools.get("pool:MINT2")!.sol, solInCurve); // money moved exactly once
assert.equal(q.events.filter(e => e.kind === "MigrateEvent").length, 1);

// failed instruction rolls back fully
const r = new LaunchpadProgram();
r.create("MINT3", "a");
const before = structuredClone(r.coins.get("MINT3")!.curve);
assert.throws(() => r.buy("x", "u", "MINT3", 10_000_000_000_000n, 285_042_333n), /ExceededSlippage/);
assert.deepEqual(r.coins.get("MINT3")!.curve, before);
console.log("events:", p.events.map(e => `${e.seq}:${e.kind}`).join(" "));
console.log("program: all checks passed");
