Welcome and the map

This book teaches you, a junior developer who knows some TypeScript, how to build a Solana bonding-curve launchpad end to end: the on-chain program, the indexer and API, and the live chart in the browser. It's written from Godspower's daily launchpad classes, and every number is checked with code.

How every chapter works

  1. Everyday analogy: a market trader, a danfo bus, a cricket scoreboard. The picture comes first.
  2. Design question: try it yourself, then open Reveal answer.
  3. Simple explanation: the idea in plain words.
  4. The math: rendered formulas with worked numbers.
  5. TypeScript code: real files you can download and run.
  6. Exercise: build it yourself, with a solution to check against.
  7. Architecture diagram: the picture of the system.
  8. Sources: the real docs, so you can check every claim.

Two kinds of facts

Real: pump.fun docs green means a real project's documented design. General pattern / our clone purple means our teaching design, a general pattern we chose. Our reading (unverified) amber means our interpretation of a project's code, which the project hasn't confirmed. We never present a purple fact as pump.fun's or Meteora's actual code.

The map of the whole system

1. On-chain program (the contract)
Global config + one curve account per coin (PDAs). Instructions create, buy, sell, migrate. Curve math, fees, slippage checks, graduation. Chapters 1 to 6.
emits events (TradeEvent, CompleteEvent, MigrateEvent) ↓
2. Indexer (backend)
WebSocket for live data + RPC backfill for gaps → raw transactions → decoded trades in Postgres, keyed by (signature, ix_path). Chapter 7.
serves candles with an as_of cursor ↓
3. API + realtime (backend → frontend)
Server-built OHLCV candles, plus a WebSocket of new trades. Chapter 8.
snapshot + live merge ↓
4. Frontend
Token page: quote with slippage, wallet signs, and a Lightweight Charts candle chart that never skips or double-counts a trade. Chapters 3 and 8.
↓ then you build it all
5. Capstone
Curve engine → program state machine → events piped into the indexer and API. Chapter 9.

Run the code

Every .ts file in this book is in the code/ folder next to the site, and every test passed when the book was built.

terminal
cd code
npm i -D tsx typescript @types/node @solana/kit
npx tsx engine.test.ts      # chapter 2 + capstone 1 numbers
npx tsx program.test.ts     # capstone 2: idempotent migrate
npx tsx fees.test.ts        # chapter 3
npx tsx pdas.test.ts        # chapter 5: pump.fun Global PDA
npx tsx security.test.ts    # chapter 6
npx tsx pipeline.test.ts    # chapters 7-8 + capstone 3 stub
